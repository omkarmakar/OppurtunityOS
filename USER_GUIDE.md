# OppurtunityOS User Guide

## Getting Started

### 1. Profile Setup
1. Upload your resume (PDF/DOCX)
2. Click "Parse & Fill" to extract data
3. A modal will show all parsed information:
   - Skills extracted from resume
   - Education details (institution, degree, field, dates)
   - Experience entries (company, role, period)
   - Projects with technologies
4. Review and save your profile

### 2. Running a Search
1. Go to the Search page
2. Configure search parameters:
   - **Max Queries**: Number of different search queries to generate (1-20)
   - **Max Results**: Results per query (1-50)
   - **Skip AI Ranking**: Skip scoring if you just want raw results
3. Click "Run Search Now"
4. View generated queries in the results - see exactly what's being searched
5. Results are automatically scored and saved

### 3. Viewing Opportunities
1. Go to Opportunities page
2. See all discovered job postings with scores (0-100)
3. Click on any opportunity to see:
   - Full job description
   - AI scoring breakdown (pros/cons)
   - Required skills vs your skills
   - Application deadline
4. Bookmark opportunities for later review
5. Track where you're applying

## How It Works

### Query Generation (AI-Powered)
The system generates intelligent search queries across multiple job boards:
- Combines your skills with job keywords
- Includes location preferences
- Targets experience level (entry-level, fresher, junior)
- Searches for remote opportunities
- Mixes specific tech stacks with general terms

**Example Queries Generated:**
- "python developer jobs Mumbai"
- "junior software engineer hiring 0-1 years experience"
- "remote backend developer positions India"
- "react javascript web developer jobs entry level"

### Opportunity Scoring (AI-Powered)
Each opportunity gets scored 0-100 based on:

**Skill Match (35%)**: Do you have the required skills?
**Role & Experience (30%)**: Is it appropriate for your level?
**Location & Work Style (15%)**: Matches your preferences?
**Compensation (10%)**: Salary expectations met?
**Opportunity Quality (10%)**: Company reputation and growth potential?

**Plus semantic analysis of:**
- Cultural fit indicators
- Hidden learning opportunities
- Deal-breakers (over-qualification, bad fit)
- Growth opportunity language
- Mentorship signals

### Real Job Boards Searched
The system searches real job sources:
- LinkedIn Jobs
- Naukri.com (India's largest job portal)
- Unstop (competitions & internships)
- Company career pages

## Tips for Best Results

### Resume Upload
- Use clear, well-formatted resumes
- Include all relevant skills and experience
- Specify target companies if known
- Include technologies/tools used

### Profile Setup
- Keep skills list updated
- Add target companies
- Specify preferred locations
- Set realistic salary expectations
- Update education and experience

### Searching
- Use multiple searches with different keywords
- Search during scheduled hours for auto-run
- Check generated queries - they show what AI is looking for
- Review scores before applying - high score = good match

### Bookmarking
- Bookmark promising opportunities
- Save deadlines to calendar
- Track companies you're interested in

## Troubleshooting

**Resume not parsing correctly?**
- Try a different PDF format
- Ensure resume is readable (not scanned image)
- Check that text is extractable

**No opportunities found?**
- Check your search queries - they're shown in results
- Add more skills to profile
- Search for "entry level" opportunities
- Try different combinations of keywords

**Low opportunity scores?**
- This might mean skills gap
- Review "missing skills" in opportunity details
- Consider learning those skills
- Search for "fresher" or "trainee" positions

**Not finding specific companies?**
- Add to target companies in profile
- Search with company name specifically
- Check LinkedIn company careers page directly
